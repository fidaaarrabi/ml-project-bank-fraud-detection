# Bank Account Fraud Detection

**Machine Learning Lab | University of Haifa**

## Project Overview

This project investigates machine learning approaches for detecting fraudulent bank account applications using the Bank Account Fraud (BAF) dataset.

The research focuses on imbalanced classification, model generalization over time, and fraud detection under limited investigation resources.

## Research Objectives

1. Explore the dataset and investigate class imbalance.
2. Develop and compare machine learning classification models.
3. Evaluate model performance across different time periods.
4. Analyze fraud detection under limited investigation capacity.
5. Investigate model performance, limitations, and trade-offs.
